# HSK AI Chat

HSK1 학습자를 위한 AI 기반 중국어 회화 학습 앱입니다.

## 프로젝트 목적

초급 학습자는 실생활에서 배운 회화를 바로 사용하기 어렵습니다.
본 프로젝트는 HSK1 수준에 맞춘 대화 흐름과 AI를 결합하여
실제 회화를 연습할 수 있는 학습 환경을 제공합니다.

## 특징
- HSK 레벨 선택
- NPC 기반 회화 학습
- FSM 기반 대화 시스템
- Rule-based 입력 검증
- Gemini / Ollama 지원
- 단어장 시스템

## Tech Stack

- Flutter
- Dart
- Hive
- Gemini API
- Ollama
- JSON

## 업데이트 계획
- 음성 인식 추가 -> 실제 대화하는 느낌의 학습
